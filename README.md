# Bugin — frontend-прототип

Кликабельный прототип приложения Bugin для Android и iOS на Flutter.
Работает на mock data: без backend, AI, авторизации, реальных броней и оплат.

## Запуск

Нужен Flutter 3.22 или новее (API сверены с исходниками Flutter 3.47.5).

```bash
cd bugin
flutter create . --platforms=android,ios --org kz.bugin   # создаст папки android/ и ios/, существующие файлы не трогает
flutter pub get
flutter run
```

Тесты:

```bash
flutter analyze
flutter test
```

## Что внутри

| Экран | Что показывает |
|---|---|
| Главная | Приветствие, поиск, быстрые намерения, «Собрать мне вечер», сценарий дня, места рядом |
| AI-поиск | Ввод запроса, примеры, недавние запросы |
| Обработка | Шаги «понял → ищу → выбираю», распознанные параметры, скелетоны |
| Результаты | «Я понял тебя» с редактируемыми параметрами, фильтры, сортировка, «Удиви меня» |
| Карточка места | Почему подходит, часы, адрес с картой, удобства, отзывы, галерея, бронь (демо) |
| Афиша | Дни, категории, «Главное на неделе», список событий |
| Карточка события | Дата, место, билеты, причины, похожие события, покупка (демо) |
| Собрать вечер | Параметры → план с таймлайном, переездами, заменой точек, сохранением |
| Избранное | Места / События / Сценарии, удаление с «Вернуть» |
| Профиль | Интересы, бюджет, статистика, уведомления |

Нижняя навигация одна на всё приложение: Главная | Афиша | Избранное | Профиль.

## Архитектура

```
lib/
├── core/        форматирование (₸, км, даты по-русски), пути к картинкам, константы
├── theme/       цвета, типографика, отступы, тема, иконки категорий
├── models/      Place, Event, Scenario, SearchIntent, Recommendation, UserProfile (+ fromJson/toJson)
├── data/        mock data — один источник правды для всех экранов
├── services/    интерфейсы репозиториев и сервисов + mock-реализации, стор избранного и профиля
├── navigation/  маршруты, типизированные переходы, вкладки
├── widgets/     переиспользуемые компоненты (PlaceCard, EventCard, ScenarioCard, …)
└── screens/     экраны
```

Экраны работают только с интерфейсами из `services/`:
`PlacesRepository`, `EventsRepository`, `SearchService`, `EveningPlanner`, `ProfileRepository`.
Чтобы подключить backend, достаточно написать реализации этих интерфейсов (REST, AI-сервис)
и собрать их в `AppServices` вместо `AppServices.mock()` — экраны менять не нужно.
Модели уже умеют `fromJson` / `toJson`, `AppImage` понимает и ассеты, и URL.

## Что стоит знать

- Фото в `assets/images` вырезаны из исходных макетов и имеют низкое разрешение — это заглушки,
  их нужно заменить на настоящие фото или URL с backend.
- Шрифт Manrope (лицензия SIL OFL, файл `assets/fonts/OFL.txt`). В нём нет символа ₸ —
  он берётся из системного шрифта автоматически.
- Все события и артисты вымышленные, даты считаются от текущего дня.
- Бронь, покупка билетов, звонки и маршруты показывают демо-сообщения.

# Bugin — frontend-прототип

Кликабельный прототип приложения Bugin для Android и iOS на Flutter.
Работает на mock data: без backend, AI, авторизации, реальных броней и оплат.
Два языка — русский и казахский. Избранное, профиль, история поиска, город и язык
сохраняются на телефоне.

## Запуск

Нужен Flutter 3.22 или новее (API сверены с исходниками Flutter 3.47.5).

```bash
cd bugin
flutter create . --platforms=android,ios,web --org kz.bugin --project-name bugin   # папки платформ, свои файлы не трогает
flutter pub get
dart run tool/setup_platforms.dart   # название Bugin, иконка, заставка, языки для iOS
flutter run
```

`tool/setup_platforms.dart` можно запускать повторно — например, после замены картинок
в `assets/branding` (иконка, заставка, подпись).

Тесты:

```bash
flutter analyze
flutter test
```

`test/screens_test.dart` открывает все экраны на обоих языках — на узком телефоне
и с крупным системным шрифтом — и падает при любом переполнении вёрстки.

## Что внутри

| Экран | Что показывает |
|---|---|
| Главная | Приветствие, поиск, быстрые намерения, «Собрать мне вечер», сценарий дня, места рядом |
| AI-поиск | Ввод запроса, примеры, недавние запросы |
| Обработка | Шаги «понял → ищу → выбираю», распознанные параметры, скелетоны |
| Результаты | «Я понял тебя» с редактируемыми параметрами, фильтры, сортировка, «Удиви меня» |
| Карточка места | Почему подходит, часы, адрес с картой, удобства, отзывы, галерея, бронь (демо) |
| Афиша | Дни, категории, «Главное на неделе», список событий |
| Карточка события | Дата, место, билеты, причины, похожие события, покупка (демо) |
| Собрать вечер | Параметры → план с таймлайном, переездами, заменой точек, сохранением |
| Избранное | Места / События / Сценарии, удаление с «Вернуть» |
| Профиль | Интересы, бюджет, статистика, уведомления, язык, сброс данных прототипа |

Нижняя навигация одна на всё приложение: Главная | Афиша | Избранное | Профиль.

## Архитектура

```
lib/
├── core/        форматирование чисел (₸, км, время), пути к картинкам, константы
├── l10n/        все тексты интерфейса на русском и казахском
├── theme/       цвета, типографика, отступы, тема, иконки категорий
├── models/      Place, Event, Scenario, SearchIntent, Recommendation, UserProfile (+ fromJson/toJson)
├── data/        mock data — один источник правды для всех экранов
├── services/    интерфейсы репозиториев и сервисов + mock-реализации, избранное, профиль,
│                история поиска, хранилище на устройстве (storage/)
├── navigation/  маршруты, типизированные переходы, вкладки
├── widgets/     переиспользуемые компоненты (PlaceCard, EventCard, ScenarioCard, …)
└── screens/     экраны
```

Экраны работают только с интерфейсами из `services/`:
`PlacesRepository`, `EventsRepository`, `SearchService`, `EveningPlanner`, `ProfileRepository`.
Чтобы подключить backend, достаточно написать реализации этих интерфейсов (REST, AI-сервис)
и собрать их в `AppServices` вместо `AppServices.mock()` — экраны менять не нужно.
Модели уже умеют `fromJson` / `toJson`, `AppImage` понимает и ассеты, и URL.

## Языки

- Тексты — в `lib/l10n`: общие (кнопки, категории, даты, цены) в `app_strings.dart`,
  тексты экранов — в `sections/`. Каждая строка записана парой «русский — казахский»:
  `tr('Собрать мне вечер', 'Маған кеш ұйымдастыр')`. Забыть перевод невозможно,
  а носителю языка удобно вычитывать оба варианта рядом.
- В экранах: `context.l10n.save`, `context.l10n.home.eveningBannerTitle`, подписи справочников —
  `context.l10n.label(place.category)`, даты и цены — `context.l10n.relativeDay(...)`, `upToTenge(...)`.
- При первом запуске берётся язык телефона (казахский или русский), дальше — выбор в профиле.
- Mock data, объяснения AI-поиска и планы вечера приходят на текущем языке — так же,
  как backend будет отвечать на заголовок `Accept-Language`. Mock-поиск понимает запросы
  на обоих языках. Сохранённые сценарии переводятся при смене языка (`EveningPlanner.localize`).
- Казахский перевод сделан без носителя языка — перед релизом его стоит вычитать.

## Сохранение данных

Хранилище — `KeyValueStore` (`lib/services/storage`): на телефоне shared_preferences,
в тестах — память. Избранное, профиль, история поиска, город и язык читаются до первого
кадра и записываются при каждом изменении. Ключи версионированы (`bugin.favorites.v1`),
повреждённые данные пропускаются. При подключении backend хранилище останется локальным кэшем.

## Что стоит знать

- Фото в `assets/images` вырезаны из исходных макетов и имеют низкое разрешение — это заглушки,
  их нужно заменить на настоящие фото или URL с backend.
- Шрифт Onest (лицензия SIL OFL, файл `assets/fonts/OFL.txt`): поддерживает весь казахский
  алфавит и знак ₸.
- Все события и артисты вымышленные, даты считаются от текущего дня.
- Бронь, покупка билетов, звонки и маршруты показывают демо-сообщения.
- Все сборки прототипа (CI и локальные) подписываются одним отладочным ключом
  `.github/android/debug.keystore` — его подключает `tool/setup_platforms.dart`, поэтому новая
  версия APK ставится поверх старой. Для публикации в магазине нужен отдельный ключ.
